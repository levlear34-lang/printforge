What this is

PrintForge turns a text description into a 3D-printable STL file, using your own Kaggle account's free GPU compute to run the actual generation. It's a personal project, not a company or a commercial product.

Inspect and test-print at your own risk.

Your Kaggle token

If you paste a token without an account, it's used only in memory for that one request and never written to disk or logged. If you create an account and explicitly choose to save a token, it's encrypted at rest and never displayed in plain text again. See the Privacy Policy for details.
